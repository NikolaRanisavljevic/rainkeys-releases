# RainKeys releases

Installers and update manifests for RainKeys, the OMFG chatters' hotkey app.

**Download the latest installer:** https://github.com/NikolaRanisavljevic/rainkeys-releases/releases/latest

1. Run `RainKeys_<version>_x64-setup.exe`.
2. On the blue "Windows protected your PC" box click **More info**, then **Run anyway**.
3. Log in with your Discord username and confirm the button the bot sends you.

Installed apps update themselves on the next launch.
